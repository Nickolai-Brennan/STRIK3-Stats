# Project Details Template

Capture project-specific information, requirements, and decisions.

## Overview
- Brief project description and objectives.
- Key stakeholders and points of contact.

## Requirements
- Functional requirements with priorities.
- Non-functional requirements (performance, security, compliance).

## Scope and Deliverables
- In-scope and out-of-scope items.
- Milestones, timelines, and success criteria.

## Current Status
- Status summary (e.g., planning, active development, maintenance).
- Recent achievements and upcoming work.

## Risks and Assumptions
- Known risks with mitigation plans.
- Assumptions that guide planning.

## Key Decisions Log
- Date, decision, decision makers, and context.

## Dependencies
- External systems, services, and teams relied upon.

## References
- Links to related docs, tickets, and dashboards.
